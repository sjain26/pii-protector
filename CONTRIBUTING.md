# Contributing to pii-protector

Thanks for helping improve **pii-protector**! 🎉

The library's source code is maintained privately, so contributions here are about **reporting problems and shaping the roadmap** — which is genuinely valuable and drives most releases.

## How you can help

### 🐛 Report a bug or a detection error
Use the [Bug report](https://github.com/sjain26/pii-detector/issues/new?template=bug_report.yml) form. The best reports include:
- A **minimal code snippet** that reproduces the issue
- The **input text** — with real personal data replaced by fake/synthetic values
- Your **version** (`pip show pii-protector`), Python version, and OS
- The **entity type** you expected vs. what you got

### 💡 Request a feature or a new PII type
Use the [Feature request](https://github.com/sjain26/pii-detector/issues/new?template=feature_request.yml) form. For a new PII type, include a **fake example** of the format and, if possible, the official spec/checksum rules.

### 💬 Ask a question or share an idea
Head to [Discussions](https://github.com/sjain26/pii-detector/discussions) — great for "how do I…", integration ideas, or anything not yet a concrete bug/feature.

### 📝 Improve the docs
Docs in this repo (README, examples) are open to pull requests. Small fixes — typos, clearer examples, better wording — are always welcome.

## ⚠️ Please never paste real PII

This is a privacy tool. When sharing sample text in issues or discussions, **always redact real personal data** and use synthetic values instead. Reports containing real personal data may be edited or removed.

## Ground rules

- Search existing issues/discussions first to avoid duplicates.
- One issue per report — separate bugs into separate issues.
- Be respectful and constructive. See the Code of Conduct expectations in the repo settings.

Every report and idea helps. Thank you! 🙏
